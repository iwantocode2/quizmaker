HOW TO UPLOAD YOUR QUIZMAKER PROJECT TO GITHUB

## 1. Sign in to GitHub

1. Open https://github.com/
2. Sign in to your GitHub account. If you do not have an account, create one.

## 2. Create a New Repository

1. Click the **+** icon near the top-right corner, then select **New repository**.
2. Enter the repository name: `QuizMaker`
3. Enter the description: `Web-based Quiz Creation and Assessment System`
4. Choose **Public** if your instructor needs to view your code. Choose **Private** if you want to restrict access.
5. You may select **Add a README file**.
6. Click **Create repository**.

## 3. Prepare Your Project Files

1. Find the folder containing your actual QuizMaker source code.
2. If your files are in a ZIP file, extract the ZIP first.
3. Prepare the project files you need, such as:

- `index.html`
- `style.css`
- `script.js`
- PHP files, such as `save.php`, `get_quizzes.php`, and `get_quiz.php`
- An SQL database export, if appropriate
- A `README.txt` or `README.md` containing a project description

## 4. Upload Your Files to GitHub

1. Open your new QuizMaker repository.
2. Click **Add file**, then **Upload files**.
3. Drag your project files and folders into the upload area, or click to select them.
4. Enter a commit message, such as:

   `Upload QuizMaker project files`

5. Click **Commit changes**.

## 5. Copy Your Repository Link

Your repository link will look like this:

`https://github.com/YOUR-USERNAME/QuizMaker`

Replace `YOUR-USERNAME` with your GitHub username. You can share this link with your instructor or teammates.

## 6. Important Security Warning

**Do not upload the following information:**

- Passwords or private login details
- Brevo API keys, Gemini API keys, or other secret tokens
- OTP codes
- Real user information or private quiz results
- Live database usernames, passwords, or private connection details

Before uploading, check `connect.php` and other configuration files. If they contain your live database credentials or secret keys, remove those secrets from the public version and use placeholders instead.

Never publish API keys in JavaScript or any other public file.

A public GitHub repository allows others to view your code. Upload only files you are allowed to share.

## 7. Final Check

1. Open your repository page after uploading.
2. Confirm that your expected files appear.
3. Open a few files on GitHub to verify that the upload completed successfully.
4. Copy your repository URL and keep it for your project documentation.

If GitHub rejects a file or the upload is too large, try uploading the project in smaller groups or use GitHub Desktop.

**Important note:** Uploading code to GitHub does not automatically deploy your PHP/MySQL website. Your hosted QuizMaker website and its online database remain separate from the GitHub repository.
